Cargando tus cotizaciones…

Lista de compra (carrito)

Buscá productos en el catálogo, armá el carrito, elegí tiendas por categoría y pulsá Cotizar. La matriz usa precios de Mongo (ventana 48 h); las celdas vacías pueden encolar scrape async y se actualizan solas.

1. Buscar productos

Solo catálogo Mongo (`/api/catalog`). Agregá con cantidad y editá el carrito abajo.

2. Carrito 0

ProductoCant.

El carrito está vacío. Buscá arriba o importá un CSV.

3. Categorías a cotizar

Marcá una o más categorías. Al cotizar se usan todas las tiendas de cada categoría seleccionada.

Cotizar responde desde Mongo (sin FlareSolverr en la petición). Misses encolan scrape async («buscando…»). Precios stale (>48 h) en amarillo; la canasta suma solo precios frescos.

Importar desde CSV (opcional)

Columnas: nombre (obligatorio); opcionales: cantidad, marca, ean, unidad. Usa las tiendas marcadas arriba. Máximo 100 productos.

Cotización con precios de referencia

Importa una cotización de proveedor con precio_unitario, revisa los datos y confirma coincidencias. Estados: borrador → revisión → comparada → exportada. Tus cotizaciones son privadas.

Precios en pesos chilenos enteros. Columnas: nombre, cantidad, precio_unitario; opcionales: marca, ean, unidad (unidad/pack/kg/litro/metro). Máximo 100 productos.

Conversión PDF (Docling async)

Solo para el modo cotización. El PDF se convierte fuera de la petición web. Si ves needs_docling, el contenedor web no tiene Docling: usá CSV aquí o el flujo offline abajo. El modo CSV nunca se bloquea.
