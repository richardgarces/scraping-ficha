Medios de alerta

Activar

El push al celular llega a quienes lo activaron en Siguiendo. Este interruptor habilita el envío; las llaves VAPID se generan solas o se leen de WEB_PUSH_VAPID_*.

Se usa el chat guardado aquí (o el de la cuenta, si tiene Telegram). Un @usuario de chat privado se resuelve al id numérico al enviar.

Pruebas de aviso

Un mensaje por clic. Telegram usa el chat guardado. El correo va al destinatario de abajo; puedes cambiarlo. El push usa los dispositivos de tu cuenta (actívalos en Siguiendo desde el celular).

Programación (cron)

En BMAX el contenedor no tiene crontab: guarda el horario aquí y el host lo instala con prod-menu opción 8 (también en cada deploy).
